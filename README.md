# Закріплення дефектів у модульних тестах, згенерованих LLM з мутаційним зворотним зв'язком

Код, дані та результати експерименту до статті.

**Дослідницьке питання:** чи збільшує мутаційний зворотний зв'язок кількість тестів, що закріплюють наявний дефект?

**Коротко про результат:** ні. На 42 функціях з HumanEvalFix тести, що закріплюють дефект, з'явилися у 30 функціях з мутаційними підказками і в 29 без них (точний тест Мак-Немара, p = 1,000). Водночас близько третини всіх згенерованих тестів закріплюють дефект незалежно від умови.

## Як влаштовано експеримент

Для кожної функції (версія з дефектом + виправлена версія) проводяться дві умови по три раунди:

| Раунд | Контрольна умова (`plain`) | Експериментальна умова (`mutation`) |
|---|---|---|
| 0 | «Напиши 5 тестів» | «Напиши 5 тестів» (той самий запит) |
| 1–2 | «Покращ набір, допиши 3 тести» | Список до 5 мутантів, яких тести не виявили, + «допиши 3 тести» |

Модель бачить лише код з дефектом. Кожен тест запускається на обох версіях коду й отримує клас:

| Клас | Код з дефектом | Виправлений код | Значення |
|---|---|---|---|
| `detects` | падає | проходить | виявляє дефект |
| `locks` | проходить | падає | закріплює дефект |
| `neutral` | проходить | проходить | не стосується дефекту |
| `broken` | падає | падає | непрацюючий тест |

- **Дані:** HumanEvalFix (Python) з [bigcode/humanevalpack](https://huggingface.co/datasets/bigcode/humanevalpack), 42 функції, по 7 з кожного з шести типів дефектів.
- **Модель:** [openai/gpt-oss-20b](https://huggingface.co/openai/gpt-oss-20b) через API [Groq](https://console.groq.com); температура 0,7, рівень міркування low, до 4000 токенів відповіді.
- **Мутації:** власний мутатор на основі AST, оператори ROR, AOR, LCR, UOD, CRP.

## Як відтворити

Потрібен Python 3.10+.

```
python -m venv .venv
.venv\Scripts\activate            # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```

Створіть ключ API на https://console.groq.com (розділ API Keys) і файл `.env`:

```
LLM_API_KEY=ваш_ключ
LLM_BASE_URL=https://api.groq.com/openai/v1
LLM_MODEL=openai/gpt-oss-20b
LLM_REASONING_EFFORT=low
LLM_MAX_TOKENS=4000
```

Запуск:

```
python prepare_data.py              # завантаження датасету -> data/humanevalfix_python.jsonl
python experiment.py --limit 42     # експеримент (252 запити до моделі)
python analyze.py                   # статистика -> results/analysis/
python plots.py                     # графіки -> results/figures/
```

Параметри `experiment.py`: `--limit` (кількість функцій, 0 = всі 164), `--repeats`, `--rounds`, `--n-initial`, `--n-new`, `--max-mutants`, `--seed`, `--temperature`, `--out`.
